Install Studio Write

Drag the app icon onto the Applications folder.

First launch needs your approval

Studio Write isn’t notarized by Apple yet, so macOS blocks the very first launch.

  1. 1 Double-click Studio Write, then click Done on the macOS alert.
  2. 2 Open System Settings ▸ Privacy & Security.
  3. 3 Under Security, click Open Anyway for Studio Write, then confirm.
Still blocked, or macOS says it’s “damaged”? Run this in Terminal: xattr -dr com.apple.quarantine "/Applications/Studio Write.app"
